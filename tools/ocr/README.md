# 그림 속 글자 뽑기 (애플 Vision · 맥에서만)

vault의 그림에서 글자와 그 자리를 뽑아 `attachments/.ocr/<그림이름>.json`에 적어둔다.
앱은 그 파일만 읽으므로 **앱은 하나도 무거워지지 않는다**.

## 왜 이 방법인가 (2026-10-16 실측)

| 방법 | 앱에 더해지는 무게 | 비용 | 한글 |
|---|---|---|---|
| **애플 Vision(여기)** | **0** — 맥에서 미리 돌린다 | 0 | 좋음 |
| Gemini vision | 0 | 부를 때마다 | 좋음 |
| Tesseract.js | **15MB**(한글 학습데이터) | 0 | 보통 |

애플 Live Text는 웹에서 부를 길이 없다(JS API가 없다). Tesseract.js는 앱이 무거워져서 뺐다.

**그림 24장을 표본으로 재어 보니 17장은 글자가 아예 없었다**(사진·x-ray·해부 그림).
그래서 글자 뽑기는 *거드는* 기능이고, 주된 길은 **손으로 네모 쳐 가리기**다.

## 쓰기

```sh
tools/ocr/run.sh                 # 안 돌린 그림만
tools/ocr/run.sh --all           # 전부 다시
```

처음 한 번은 몇 분 걸리고(그림 1,276장 · 평균 0.2초), 그다음부터는 새 그림만 돈다.

## 나오는 꼴

```json
{"w":1866,"h":1400,"ms":1866,"n":37,
 "lines":[{"t":"직접사인","x":0.08,"y":0.21,"w":0.33,"h":0.02,"conf":1.00}]}
```

자리는 **비율**(0~1, 왼쪽 위 기준)이라 그림을 줄여도 그대로 맞는다.
`conf`가 0.9 미만인 줄은 앱이 숨긴다 — 빽빽한 도표에서 엉뚱하게 읽은 것들이다.
