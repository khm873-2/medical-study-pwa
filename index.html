GitHub 연결

이 앱은 비공개 vault 저장소(khm873-2/medical-vault)에서 모의고사를 읽어오고, 풀이 결과를 거기에 저장합니다. 그래서 읽기·쓰기 권한이 있는 토큰이 한 번 필요합니다.

토큰 발급 방법 (처음 한 번만)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Repository access → Only select repositories → medical-vault 하나만 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. Expiration → 90 days (만료일에 갱신 리마인더를 걸어두세요)
  6. Generate 후 나오는 github_pat_... 문자열을 아래에 붙여넣기

오프라인 저장

과목을 저장해두면 네트워크 없이도 풀 수 있고, 검색 범위에도 들어옵니다. (한 번 열어본 자료는 자동으로 저장됩니다.)

백업 · 복원

iOS는 홈화면 아이콘을 지우면 앱 데이터를 통째로 지웁니다. 플래시카드 일정·풀던 시험·저장 대기 중인 결과를 비공개 vault에 자동으로 백업해둡니다. (보안상 GitHub 토큰과 Gemini 키는 백업하지 않습니다 — 다시 설치하면 그 둘만 넣으면 됩니다.)

AI 질문 (Gemini)

키를 넣으면 밑줄 친 내용에 대한 답변이 화면을 떠나지 않고 옆에 뜹니다. 비워두면 ChatGPT·Claude 앱으로 넘기는 기존 방식으로 동작합니다.

키 발급 방법 (무료, 1분)
  1. aistudio.google.com/apikey 접속
  2. Create API key → 프로젝트 선택(없으면 자동 생성)
  3. 나오는 AIza... 문자열을 아래에 붙여넣기

개인 학습 사용량이면 무료 한도 안에서 충분합니다.
