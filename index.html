GitHub 연결

이 앱은 비공개 vault 저장소(khm873-2/medical-vault)에서 모의고사를 읽어오고, 풀이 결과를 거기에 저장합니다. 그래서 읽기·쓰기 권한이 있는 토큰이 한 번 필요합니다.

토큰 발급 방법 (처음 한 번만)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Repository access → Only select repositories → medical-vault 하나만 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. Expiration → 90 days (만료일에 갱신 리마인더를 걸어두세요)
  6. Generate 후 나오는 github_pat_... 문자열을 아래에 붙여넣기

검색 범위

vault의 글 전체(노트·족보·퀴즈 — 약 20MB)를 한 번 받아두면 열어본 적 없는 자료도 찾힙니다. 그다음부터는 바뀐 것만 받으므로 금방 끝납니다.

개인 학습 사용량이면 무료 한도 안에서 충분합니다.

무료 등급은 구글이 모델 개선에 씁니다. 긁어서 물어본 노트 글·질문이 사람 검토를 거쳐 학습에 쓰일 수 있습니다(구글 약관). 유료(결제 등록) 등급은 학습에 쓰이지 않습니다 — 공부 자료가 밖으로 나가는 게 싫으면 console.cloud.google.com 에서 결제를 등록하세요. 쓴 만큼만 나가고, 개인 학습량이면 월 몇백 원 수준입니다.
※ 환자 정보는 어느 등급이든 넣지 마세요 — 이 앱은 강의 노트용입니다.
