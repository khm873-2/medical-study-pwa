GitHub 연결

이 앱은 비공개 vault 저장소(khm873-2/medical-vault)에서 모의고사를 읽어오고, 풀이 결과를 거기에 저장합니다. 그래서 읽기·쓰기 권한이 있는 토큰이 한 번 필요합니다.

토큰 발급 방법 (처음 한 번만)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Repository access → Only select repositories → medical-vault 하나만 선택
  4. Permissions → Repository permissions → Contents → Read and write
  5. Expiration → 90 days (만료일에 갱신 리마인더를 걸어두세요)
  6. Generate 후 나오는 github_pat_... 문자열을 아래에 붙여넣기
